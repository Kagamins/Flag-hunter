# 🚩 صائد الأعلام — حقيبة أدوات CTF

مجموعة أدوات CTF سريعة تعمل بالكامل داخل المتصفح: بلا خادم، بلا ذكاء اصطناعي، ولا يُرفع أي ملف. انشرها على GitHub Pages وشارك الرابط مع طلابك.

## الأدوات

| التبويب | ماذا يفعل |
|---|---|
| 🔎 **الفحص السريع** | الصق أي نص أو اسحب أي ملف، فيبحث عن العلم في النص المباشر وفي ROT1–25 و ROT47 و Atbash والنص المعكوس، ويفك كل مقطع Base64/Hex/Binary/Morse/URL حتى 5 طبقات. وللملفات: البيانات الوصفية، والبيانات بعد نهاية الملف، ومحتويات ZIP/GZIP، و56 تركيبة LSB للصور. |
| 🧩 **فك الترميز** | فك تلقائي متعدد الطبقات مرتب حسب سهولة القراءة، مع وصفة يدوية (فك / تحويل / ترميز / تشغيل Brainfuck)، و**فك JSFuck** الآمن (يلتقط الكود المخفي كنص دون تشغيله). |
| 🔐 **الشيفرات** | تخمين بضغطة واحدة: قيصر، Atbash، ROT47، Affine، السياج المتعرج، حل Vigenère التلقائي، Bacon، و XOR. ويضم أيضاً Vigenère بمفتاح، واسترجاع مفتاح XOR من `flag{`، ومساعد الاستبدال، وتحليل التكرار. |
| 🗂️ **تحليل الملفات** | النوع الحقيقي، والملفات المضمّنة، والبيانات بعد النهاية، ومحتويات ZIP، وبيانات EXIF مع GPS، وإصلاح أبعاد PNG، وطبقات البتات، واستخراج LSB، والمخطط الطيفي للصوت، والنصوص، وعرض Hex. |
| #️⃣ **الهاش والأرقام** | التعرّف على الهاش، وفك JWT، وحساب الهاش (نص/hex/base64)، و**كسر الهاش** (قائمة شائعة + قوة غاشمة لـ MD5/SHA-1/SHA-256)، وفحص كلمات مرشحة، ومحوّل الأرقام، ومساعد RSA. |
| 🌐 **الويب** | رفيق Burp Suite: الصق طلب أو استجابة HTTP فتُفكّ الكوكيز والمعاملات والترويسات و JWT تلقائياً، مع تعليقات HTML والحقول المخفية وأمر curl، ومقارن (Comparer) بين ردّين. |
| 🔁 **فك أسّي** | فك RSA ومقلوب الأسّ النمطي لتحديات `c ≡ secret^e mod n`: يحسب رتبة الزمرة (n−1 إن كان n أوّلياً، أو φ من p·q أو من العوامل، مع اختبار أوّلية وتحليل تلقائي)، ثم `d = e⁻¹ mod order` و `secret = c^d mod n`، ويتحقّق بإعادة التشفير. الحقول تقبل صيغاً مثل `2^136+85`. |
| 🐍 **بايثون** | محرّك بايثون حقيقي (Pyodide) داخل المتصفح لعكس سكربتات التشفير: ألصق السكربت، ارفع الملف المشفّر (متاح كـ `data`)، واكتب فكّ التشفير، أو اضغط **«اعكس تلقائياً»** ليجرّب عكس السكربت آلياً (عمليات بايت-ببايت/إعادة ترتيب بلا مفتاح) ويتحقّق بإعادة التشفير. يعمل بدون إنترنت بعد أول تحميل. |
| 🎯 **التدريب** | 19 مهمة تدريبية بنقاط خبرة وتلميحات وأوسمة. |
| 📖 **الدليل السريع** | «إذا رأيت كذا، جرّب كذا» لكل الفئات، مع قسم **أمن الويب** (حقن SQL وخدع PHP مع الدفاعات) وحمولات قابلة للنسخ بضغطة. |

**نظام اللعب:** نقاط خبرة، و7 مستويات (من مبتدئ إلى أسطورة CTF)، و17 وساماً، واحتفال عند العثور على علم. التقدّم محفوظ في متصفح كل طالب.

اختصارات: `Alt+1`…`Alt+8` للتبويبات، و `Ctrl+Enter` للتشغيل. ويمكن سحب أي ملف إلى أي مكان في الصفحة.

## النشر على GitHub Pages (5 دقائق تقريباً)

1. أنشئ مستودعاً **عاماً** جديداً في github.com، مثلاً `flag-hunter`.
2. اضغط **Add file ← Upload files**، واسحب **كل محتويات هذا المجلد**، ثم Commit.
3. اذهب إلى **Settings ← Pages**، واختر **Deploy from a branch** والفرع **main** والمجلد **/ (root)**، ثم **Save**.
4. بعد دقيقة تقريباً يصبح الموقع على: `https://<اسم-المستخدم>.github.io/flag-hunter/`

**بدون إنترنت:** يمكن لكل طالب تنزيل المستودع (**Code ← Download ZIP**) وفتح `index.html` مباشرة.

## ملاحظات

- HTML/CSS/JS فقط، بلا مكتبات خارجية (عدا خط Cairo من Google Fonts، وله بديل تلقائي بدون إنترنت).
- «اعكس تلقائياً» يعكس التحويلات القابلة للعكس بلا مفتاح (XOR/جمع/تدوير/استبدال/إعادة ترتيب وتركيباتها) بمعاملة `encrypt()` كصندوق أسود والتحقّق بإعادة التشفير؛ يتوقّف بصراحة عند التشفير بمفتاح أو الكتلي (AES) أو دوال الهاش أو أي تحويل يفقد المعلومات.
- بايثون في تبويب «بايثون»: المكتبة القياسية تعمل بلا إنترنت؛ مكتبات مثل pycryptodome (AES) تحتاج إنترنت أول مرة عبر micropip.
- الهاش (MD5/SHA) **لا يُفكّ** — هو باتجاه واحد. «كسر الهاش» يجرّب كلمات/احتمالات فقط، وينجح إن كان الأصل قصيراً أو شائعاً.
- غير مشمول: اعتراض حركة الشبكة نفسها (يحتاج Burp Suite على الحاسوب أو تطبيقاً مثل HTTP Catcher / Proxyman على الآيباد، أو Reqable / PCAPdroid / HTTP Toolkit على أندرويد)، وكسر كلمات السر، والهندسة العكسية. الدليل السريع في الموقع يشرح Burp وبدائل الآيباد وأندرويد وسير العمل على الجوال.
- حمولات أمن الويب (SQLi/PHP) مرجع تعليمي لتحديات CTF والاختبار المصرّح به فقط — لا تُستخدم على أي نظام بلا إذن صريح.
- للاستخدام في المسابقات والأنظمة المصرّح بها فقط.
